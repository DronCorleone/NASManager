# NAS Manager 1.1.0

Исправление подключения к TrueNAS SCALE 25.10 и диагностированных проблем dashboard.

> Важно: релиз подписан новым постоянным ключом. Перед установкой удалите v1.0.0 — Android не разрешает обновление приложения с другой подписью. Последующие версии можно будет устанавливать поверх v1.1.0.

- Удалён недопустимый параметр `reconnect_token` из `auth.login_ex` для TrueNAS 25.10.
- Полностью удалён автоматический REST fallback, вызывавший `RESTAPIUsage` и повторные действия.
- API key больше невозможно отправить через HTTP/WS: требуется HTTPS/WSS.
- Добавлена поддержка установленных пользователем Android CA при сохранении проверки hostname.
- Исправлены параметры и ожидание job-операций Start / Stop / Redeploy / Upgrade / Shutdown.
- Исправлено ложное отображение CPU 100%; load average теперь показан отдельно.
- RAM показывает used/total только при наличии realtime-метрики.
- Даты алертов преобразуются из epoch/ISO в локальное время, HTML очищается.
- Ошибки TLS, авторизации и действий показываются полностью в копируемом диалоге.
- Настройки явно требуют HTTPS и имя владельца API key.

Поддерживается Android 8.0 (API 26) и новее. Целевая версия сервера — TrueNAS SCALE 25.04 и новее.
