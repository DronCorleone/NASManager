# NAS Manager 1.2.0

Локальное HTTP-подключение стало основным режимом для серверов TrueNAS без доступного SSL-сертификата. HTTPS сохранён как дополнительный защищённый вариант.

- Добавлено подключение к `http://` через JSON-RPC WebSocket `ws://.../api/current`.
- HTTP-аутентификация использует имя пользователя и пароль (`PASSWORD_PLAIN`).
- Для HTTP рекомендуется отдельный служебный пользователь без 2FA и с минимально необходимыми ролями.
- API key никогда не отправляется по HTTP: TrueNAS автоматически отзывает ключи после использования через незащищённый транспорт.
- HTTPS/WSS сохранён; при наличии API key он используется предпочтительно, также поддерживается пароль.
- В настройках появились отдельные поля пароля и API key, а подсказки объясняют выбор по схеме URL.
- Пароль, как и API key, хранится на устройстве в зашифрованном виде через Android Keystore.
- Сообщения диагностики различают ошибки HTTP/password и HTTPS/API key/certificate.
- Документация дополнена настройкой HTTP-порта, отключением HTTP→HTTPS redirect, ролями служебного пользователя и правилами безопасного использования в LAN/VPN.

> Важно: HTTP не шифрует имя пользователя, пароль и данные TrueNAS в сети. Используйте его только в доверенной локальной сети либо внутри VPN. Не пробрасывайте порт Web UI/API TrueNAS в интернет.

Поддерживается Android 8.0 (API 26) и новее. Целевая версия сервера — TrueNAS SCALE 25.04 и новее.
